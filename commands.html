Command-line tools

All commands are subcommands of sflow. Every command accepts -h/--help and the common logging options --logdir, --debug, -v/--verbose and -q/--quiet.

Example, run from examples/sac_sjr_flux:

sflow plot scenario.yml -o figs        # figs/sac.png, figs/sjr.png
sflow plot scenario.yml --series sac --show
sflow plot scenario.yml --gui          # interactive Assembly Preview mock

sflow

scenarioflow command-line tools.

Usage

sflow [OPTIONS] COMMAND [ARGS]...

Options

-V, --version

Show the version and exit.

-h, --help

Show this message and exit.

plot

Run scenario CONFIG and plot components with the assembled series.

Usage

sflow plot [OPTIONS] CONFIG

Options

--series <NAME>

Series to plot (repeatable). Default: all.

-o, --output, --out <output>

Output file or directory.

--show

Show interactive window.

--gui

Open the interactive Assembly Preview timeline mock.

--logdir <logdir>

Directory for a timestamped log file.

--debug

Debug-level logging.

-v, --verbose

Increase verbosity; -vv is debug.

-q, --quiet

Suppress console logging (file logging via –logdir continues).

-h, --help

Show this message and exit.

Arguments

CONFIG

Required argument
